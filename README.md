# SIDHRA GARMENTS - Workshop Management System PWA

Production web application suite for SIDHRA GARMENTS tailoring and order management.

## Included Files
- `index.html` - Main application interface & Service Worker loader.
- `manifest.json` - PWA Web App Manifest for mobile installation.
- `sw.js` - Service Worker for offline availability and asset caching.
- `icon-192.svg` - Mobile homescreen icon (192x192).
- `icon-512.svg` - High-res PWA splash icon (512x512).

## Deployment Guide

### GitHub Pages Deployment
1. Push all files in this directory to your GitHub repository main branch.
2. Go to **Settings > Pages**.
3. Under **Source**, select `Deploy from a branch` and pick `main` / `/ (root)`.
4. Click **Save**. Your PWA is now live with free HTTPS!

### Vercel / Netlify Deployment
1. Drag and drop this extracted folder onto Vercel or Netlify dashboard.
2. Deploy instantly with built-in HTTPS required for PWAs.
